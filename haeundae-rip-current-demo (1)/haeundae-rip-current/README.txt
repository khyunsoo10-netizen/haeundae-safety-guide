해운대해수욕장 이안류 다국어 안전안내 시범사이트

1. index.html 및 images 폴더 전체를 동일한 구조로 웹 호스팅에 업로드합니다.
2. 사이트 주소가 발급되면 해당 URL로 QR코드를 생성합니다.
3. QR코드 스캔 → 언어 선택 → 해당 언어 안내판 이미지가 표시됩니다.
4. 직접 특정 언어로 연결하려면 URL 끝에 #ko, #zh, #ja, #th, #vi, #fr를 붙일 수 있습니다.
5. 시범 번역 이미지이므로 공공장소 설치 전 원어민 번역 검수와 안전수칙 검토가 필요합니다.
6. 실제 긴급연락처나 기관 명칭은 검토 후 추가하세요.
